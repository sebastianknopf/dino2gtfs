# GTFS Mapping Specification

The mapping from DINO to GTFS is up to the profiles. See [docs/dev/profiles](docs/dev/profiles) for specific mappings of the profiles.

The specification is a design contract, not a claim of completed conversion support. The target format follows https://gtfs.org/documentation/schedule/reference/. 

Additionally, following proposals and PRs are considered:
- Notices extension from https://github.com/google/transit/pull/638.
